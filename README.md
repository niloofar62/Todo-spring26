## Overview

This is a full-stack Todo application built with React and a REST API backend. Users can securely log in, create tasks, edit existing tasks, mark tasks as completed, and organize their work using sorting and filtering features.

The project was built as part of my Code the Dream coursework and demonstrates modern React development practices including authentication, state management, routing, and API integration.

---

## Features

* User authentication and protected routes
* Create new todos
* Edit existing todos
* Mark todos as completed
* Filter todos by search term
* Sort todos by different criteria
* Responsive design for mobile and desktop
* Error handling and validation
* Debounced search input

## Design Decisions

One of my primary goals was to create a maintainable application structure. To achieve this, I used React Context for authentication management, which eliminated prop drilling across components. I also refactored complex state management into a reducer pattern using useReducer, making application behavior more predictable and easier to maintain.

For user experience, I implemented optimistic updates, debounced searching, input validation, and error handling to provide responsive feedback while interacting with the application.

---

## Challenges and Lessons Learned

The most challenging aspect of this project was transitioning from multiple useState hooks to a centralized reducer architecture and implementing Context API for authentication. Through debugging API requests, authentication flows, and state updates, I gained a deeper understanding of React application structure and state management patterns.
